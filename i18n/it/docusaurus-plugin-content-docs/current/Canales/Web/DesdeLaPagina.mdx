# Dalla pagina

La scheda **Sviluppatore** di [Web Chatbot Widget](./setup) è per chi incorpora la chat. Se il sito incolla soltanto lo snippet, non serve entrare qui.

## Variabili di contesto

Ogni riga è un nome e un valore. Viaggiano in ogni messaggio e il bot le legge come qualsiasi variabile, con `{$nombre}`.

Servono da valore predefinito. Se la pagina chiama `injectContext`, quei valori coprono quelli del pannello. Una variabile definita qui è già nel primo turno, quello del benvenuto.

**Salva modifiche** le lascia nel widget. Senza salvare, la pagina di prova non le vede.

## Modalità debug

L'interruttore **Modalità debug** mette un pulsante di ispezione accanto a ogni messaggio del bot. Apre la request e la response di quel turno. Serve a controllare il widget pubblicato. La console del pannello ha la sua, in [Provare il bot](/docs/Fundamentos/ProbarElBot).

## Controllare la chat

L'avviso del pannello lo dice: è facoltativo. Serve se la pagina ha un pulsante proprio, o se c'è un utente con sessione.

L'elemento è `treeflow-widget`.

**Aprire o ridurre**

```javascript
const widget = document.querySelector('treeflow-widget');
widget.open();
widget.close();
```

**Modalità scura**, a parte l'interruttore di [Colori](./personalizacion#colores):

```javascript
const widget = document.querySelector('treeflow-widget');
widget.setAttribute('dark-mode', 'true');
widget.removeAttribute('dark-mode');
```

**Dati di chi è nella pagina.** Coprono le variabili del pannello. Il bot le usa come `{$nombre}`.

```javascript
const widget = document.querySelector('treeflow-widget');
widget.injectContext({
  usuarioId: 'usr_987',
  nombre: 'María González',
  plan: 'Empresarial'
});
```

**Mandare un testo** come se l'avesse scritto la persona:

```javascript
const widget = document.querySelector('treeflow-widget');
widget.sendUserMessage('Hola, necesito ayuda con mi pedido');
```

**Svuotare la conversazione** e iniziarne un'altra sessione:

```javascript
const widget = document.querySelector('treeflow-widget');
widget.clearHistory();
```

Lo stesso codice è nella scheda, con un pulsante **Copia** per caso.
