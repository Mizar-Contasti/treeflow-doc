# Credenciais

**Credenciais** está em Gestão. Ali se criam as chaves com as quais algo de
fora fala com o workspace.

Há duas abas e as duas leem a mesma tabela:

- **Chaves de API.** Para CI, um SDK ou um script.
- **MCP.** Para que Claude Desktop, Claude Code ou Cursor usem a árvore. Ao criar a chave, o app copia o JSON pronto. O percurso está em [MCP](/docs/Agente/Mcp).

Criá-las é de administrador. A chave completa se mostra uma vez, ao criá-la.
Depois só fica o identificador.

![Credenciais, aba Chaves de API. A outra aba é MCP](/img/gestion/credenciales.png)

Não confundir com as chaves dos modelos de IA do agente construtor: essas
se guardam por workspace na configuração do agente, não nesta página.
