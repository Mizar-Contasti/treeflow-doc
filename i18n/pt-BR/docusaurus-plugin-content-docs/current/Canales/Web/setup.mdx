# Widget web

O **widget web** é o chat que se cola em um site. Não pede token: liga-se, ajusta-se no painel e copia-se um snippet. É um canal **Estável**.

![Web Chatbot Widget, com o estado Ativa e a aba Funcionalidade](/img/canales/web.png)

## Ativá-lo

A árvore precisa estar **treinada**. Caso contrário, o interruptor não passa para Ativa e a tela avisa «Bot não treinado».

1. Escolha o bot no canto superior esquerdo.
2. Abra **Integração → Canais → Web Chatbot Widget**.
3. Ligue **Estado**. Ele passa para **Ativa** e as abas aparecem.
4. Ajuste o que for preciso e clique em **Salvar alterações**, no canto superior direito. O ponto laranja do botão avisa que há alterações sem salvar.

| Aba | Para quê |
|---|---|
| [Funcionalidade](./Funcionalidad) | A intenção ao abrir, arquivos, o atraso e o microfone |
| [Textos, Cores, Tamanhos e Responsivo](./personalizacion) | Como ele aparece |
| [Desenvolvedor](./DesdeLaPagina) | Variáveis que viajam com cada mensagem, o modo debug e o controle a partir da página |

O ícone de copiar, à direita das abas, copia o snippet. O ao lado restaura as opções para os valores de fábrica.

Acima também estão **Testar agora** e **Abrir página de teste**.

## Colá-lo no site

O snippet já traz o script, o endereço deste TreeFlow e o id da árvore. Não é preciso preencher o id à mão. Cole antes de `</body>`:

```html
<script src="https://cdn.jsdelivr.net/gh/Mizar-Contasti/treeflow-web-widget@main/dist/treeflow-widget.js"></script>

<treeflow-widget
  endpoint="https://tu-servidor/message"
  tree-id="el-id-de-tu-arbol">
</treeflow-widget>
```

`endpoint` e `tree-id` já saem preenchidos ao copiar. Cores, textos e a intenção de início não vão no HTML: o widget os pede ao carregar, a partir do que estiver **salvo**.

Com o canal desligado, o widget deixa de responder.

## Testá-lo {#probarlo}

**Testar agora** abre o chat dentro do painel, com o que está na tela, mesmo que não esteja salvo. Clique de novo e o botão passa a dizer **Parar de testar**.

**Abrir página de teste** abre uma página em branco, sem login, só com este bot. Usa o que está **salvo**. Se você mudar uma cor e não salvar, a pré-visualização e essa página não coincidem. O mesmo link reflete o último que você salvou.

Em produção, o link sai da API (`https://api.tree-flow.com/widget-demo/…`). No ambiente local, aponta para a sua máquina.

## Se não aparecer

- O script precisa carregar. Confira no console do navegador.
- O `tree-id` é o do snippet, não um escrito à mão.
- O interruptor precisa estar em **Ativa** e a árvore treinada.
- Quem escreve pela web recebe a aba **Web** da mensagem. Se ela estiver vazia, recebe **Geral**. O detalhe está em [Mensagens](/docs/Fundamentos/Mensajes).
