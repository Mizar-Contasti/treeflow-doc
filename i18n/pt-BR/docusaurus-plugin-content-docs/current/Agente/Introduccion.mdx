# A IA no TreeFlow

O TreeFlow usa um modelo de linguagem para **ajudar você a construir** o bot. Não o usa para **responder** aos seus usuários.

:::info O bot responde com o que você constrói
Quando alguém escreve, o bot detecta uma intenção e responde com o fluxo e as mensagens da árvore. Não há um modelo generativo inventando respostas na conversa. É isso que o torna previsível: diz o que você, ou o agente, deixou escrito.
:::

## Onde há IA

| Função | Para quê | Onde |
|---|---|---|
| [**Agente construtor**](/docs/Agente/Constructor) | Criar e modificar fluxos, nós, intenções, entidades e mensagens conversando | Console → aba **Agente** |
| [**Servidor MCP**](/docs/Agente/Mcp) | Para que o Claude Desktop, o Claude Code ou o Cursor façam o mesmo de fora | Gestão → [Credenciais](/docs/Avanzado/Credenciales) → **MCP** |
| **Ingestão generativa** | Extrair intenções e entidades de um PDF ou de um CSV | Integração → Ferramentas → **Ingestão generativa** e **Base de conhecimento** |

O agente e a ingestão usam **a sua própria chave** de um provedor de modelos: o TreeFlow não traz um modelo próprio. Ver [Provedores e modelos](/docs/Agente/ModelosGenerativos).
