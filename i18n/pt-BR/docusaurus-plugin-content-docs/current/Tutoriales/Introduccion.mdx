# Tutoriais

Guias curtos, em ordem, com as telas da árvore **Cafetería** (ramo Restaurante). Cada um faz uma só coisa. Se você quiser o detalhe de cada botão, no final está o link para a página de referência.

## O percurso

1. [Criar uma árvore](./CrearChatbotBasico). Entrar, plantar com o ramo e ver o que já vem.
2. [Testar no console](./ProbarEnLaConsola). Escrever, ler a resposta e ligar o modo debug.
3. [Pedir um dado que falta](./PedirUnDato). Um parâmetro obrigatório e a pergunta que o pede.
4. [Uma mensagem com uma função](./MensajeConFuncion). Colocar no texto o que a pessoa já disse.
5. [Uma resposta para a web](./RespuestaEnLaWeb). O texto de Default e os elementos enriquecidos do canal web.
6. [Passar a conversa para uma pessoa](./PasarAUnAsesor). A intenção de atendente e a mesa de ajuda.
7. [Executar uma suíte de testes](./CorrerUnaSuite). Um CSV com o que o bot deve responder.
