# Widget web

Le **widget web** est le chat que l'on colle sur un site. Il ne demande pas de jeton : on l'active, on le règle dans le panneau et on copie un snippet. C'est un canal **Stable**.

![Web Chatbot Widget, avec l'état Active et l'onglet Fonctionnalité](/img/canales/web.png)

## L'activer

L'arbre doit être **entraîné**. Sinon, l'interrupteur ne passe pas à Active et l'écran avertit « Bot non entraîné ».

1. Choisissez le bot en haut à gauche.
2. Ouvrez **Intégration → Canaux → Web Chatbot Widget**.
3. Activez **État**. Il passe à **Active** et les onglets apparaissent.
4. Réglez ce qu'il faut et cliquez sur **Enregistrer les modifications**, en haut à droite. Le point orange du bouton signale des modifications non enregistrées.

| Onglet | À quoi il sert |
|---|---|
| [Fonctionnalité](./Funcionalidad) | L'intention à l'ouverture, les fichiers, le délai et le microphone |
| [Textes, couleurs, tailles et responsive](./personalizacion) | L'apparence |
| [Développeur](./DesdeLaPagina) | Les variables qui voyagent avec chaque message, le mode debug et le contrôle depuis la page |

L'icône de copie, à droite des onglets, copie le snippet. Celle d'à côté rétablit les options aux valeurs d'usine.

En haut se trouvent aussi **Essayer maintenant** et **Ouvrir la page de test**.

## Le coller sur le site

Le snippet contient déjà le script, l'adresse de ce TreeFlow et l'identifiant de l'arbre. Il n'y a pas à remplir l'identifiant à la main. On le colle avant `</body>` :

```html
<script src="https://cdn.jsdelivr.net/gh/Mizar-Contasti/treeflow-web-widget@main/dist/treeflow-widget.js"></script>

<treeflow-widget
  endpoint="https://tu-servidor/message"
  tree-id="el-id-de-tu-arbol">
</treeflow-widget>
```

`endpoint` et `tree-id` sont déjà remplis au moment de la copie. Les couleurs, les textes et l'intention de démarrage ne vont pas dans le HTML : le widget les demande au chargement, d'après ce qui est **enregistré**.

Avec le canal désactivé, le widget cesse de répondre.

## L'essayer {#probarlo}

**Essayer maintenant** ouvre le chat dans le panneau, avec ce que vous avez à l'écran, même si ce n'est pas enregistré. Cliquez de nouveau et le libellé devient **Arrêter le test**.

**Ouvrir la page de test** ouvre une page blanche, sans connexion, avec seulement ce bot. Elle utilise ce qui est **enregistré**. Si vous changez une couleur sans enregistrer, l'aperçu et cette page ne coïncident pas. Le même lien reflète le dernier enregistrement.

En production, le lien vient de l'API (`https://api.tree-flow.com/widget-demo/…`). En local, il pointe vers votre machine.

## S'il n'apparaît pas

- Le script doit se charger. Vérifiez-le dans la console du navigateur.
- Le `tree-id` est celui du snippet, pas un identifiant saisi à la main.
- L'interrupteur doit être sur **Active** et l'arbre entraîné.
- La personne qui écrit sur le web reçoit l'onglet **Web** du message. S'il est vide, elle reçoit **General**. Le détail est dans [Messages](/docs/Fundamentos/Mensajes).
