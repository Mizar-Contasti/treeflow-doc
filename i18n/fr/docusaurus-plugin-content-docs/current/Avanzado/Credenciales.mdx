# Identifiants

**Identifiants** est dans Gestion. C'est là que se créent les clés avec lesquelles quelque chose
de l'extérieur parle au workspace.

Il y a deux onglets et les deux lisent la même table :

- **Clés d'API.** Pour la CI, un SDK ou un script.
- **MCP.** Pour que Claude Desktop, Claude Code ou Cursor utilisent l'arbre. En créant la clé, l'application copie le JSON prêt. Le parcours est dans [MCP](/docs/Agente/Mcp).

Les créer est réservé à l'administrateur. La clé complète s'affiche une fois, à la création.
Ensuite, il ne reste que l'identifiant.

![Identifiants, onglet Clés d'API. L'autre onglet est MCP](/img/gestion/credenciales.png)

Ne pas confondre avec les clés des modèles d'IA de l'agent constructeur : celles-là
s'enregistrent par workspace dans la configuration de l'agent, pas sur cet écran.
