# Lancer une suite de tests

La [console](./ProbarEnLaConsola) est un chat, tour par tour. Une **suite** est une liste de conversations avec ce que le bot doit répondre. Elle sert à répéter la même commande après avoir changé un motif.

## Entraîner d'abord

Le bouton d'exécution reste désactivé si l'arbre n'est pas entraîné. L'éclair du menu en vert est le signe que l'entraînement est à jour.

![Le panneau, avec l'entraînement à jour](/img/intro/panel.png)

## Où c'est

**Opération → Tests**. S'il n'y a pas encore de suites, on en crée une et on envoie un CSV, ou on écrit les tours à l'écran.

![Tests : on les crée et on envoie un CSV](/img/pruebas/lista.png)

## Le fichier

Une ligne par tour. Le même `caso` est une conversation. Chaque cas démarre avec sa propre session : la commande précédente ne passe pas à la suivante.

```csv
caso,turno,mensaje,intencion,respuesta_contiene,slot,parametros,evento
pedido por partes,1,quiero empanadas,hacer_pedido,¿De qué sabor,sabor_producto,,
pedido por partes,2,de queso,,¿Cuántas,numero,,
pedido por partes,3,dos,,Anoté,,numero=2;sabor_producto=queso,
```

| Colonne | Ce qu'elle exige |
|---|---|
| `intencion` | L'intention détectée est celle-là |
| `respuesta_contiene` | La réponse contient ce texte, sans distinguer les majuscules |
| `slot` | Le paramètre que le bot demande à ce tour |
| `parametros` | Les valeurs capturées. Plusieurs dans la même cellule : `nombre=valor;nombre=valor` |
| `evento` | L'événement résultant |

Les colonnes vides ne vérifient rien. Le CSV minimal est `caso,turno,mensaje`. Si le fichier est mauvais, l'écran montre la ligne et le motif.

Le crayon ouvre le cas. **Enregistrer** écrit les modifications. **Abandonner** les lâche.

## Le résultat

Exécuter lance cette suite contre l'entraînement actuel. L'historique garde avec lequel elle a été mesurée. Les cas qui échouent s'ouvrent et montrent ce qui était attendu et ce que le bot a répondu. Comparer deux exécutions dit ce qui passait avant et échoue maintenant, et ce qui échouait et passe maintenant.

Les sessions de l'exécution ne restent pas dans Conversations.

Pour regarder un tour isolé, avec l'intention et les paramètres, utilisez la console en mode debug. Le détail de la suite est dans [Tests](/docs/Avanzado/Pruebas).
