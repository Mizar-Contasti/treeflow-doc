# Tutoriels

Des guides courts, dans l'ordre, avec les écrans de l'arbre **Cafetería** (secteur Restaurant). Chacun ne fait qu'une chose. Si vous voulez le détail de chaque bouton, le lien vers la page de référence est à la fin.

## Le parcours

1. [Créer un arbre](./CrearChatbotBasico). Entrer, planter avec le secteur et voir ce qu'il apporte déjà.
2. [Tester dans la console](./ProbarEnLaConsola). Écrire, lire la réponse et activer le mode debug.
3. [Demander une donnée manquante](./PedirUnDato). Un paramètre requis et la question qui le demande.
4. [Un message avec une fonction](./MensajeConFuncion). Mettre dans le texte ce que la personne a déjà dit.
5. [Une réponse pour le web](./RespuestaEnLaWeb). Le texte de Default et les éléments enrichis du canal web.
6. [Passer la conversation à une personne](./PasarAUnAsesor). L'intention de conseiller et le service d'assistance.
7. [Lancer une suite de tests](./CorrerUnaSuite). Un CSV avec ce que le bot doit répondre.
