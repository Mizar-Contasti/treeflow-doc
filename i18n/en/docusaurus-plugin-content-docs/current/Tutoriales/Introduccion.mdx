# Tutorials

Short guides, in order, with the screens of the **Cafetería** tree (Restaurant industry). Each one does a single thing. If you want the detail of every button, the link to the reference page is at the end.

## The path

1. [Create a tree](./CrearChatbotBasico). Sign in, plant with the industry, and see what it already includes.
2. [Test in the console](./ProbarEnLaConsola). Type, read the reply, and turn on debug mode.
3. [Ask for a missing value](./PedirUnDato). A required parameter and the question that asks for it.
4. [A message with a function](./MensajeConFuncion). Put into the text what the person already said.
5. [A reply for the web](./RespuestaEnLaWeb). The Default text and the web channel's rich elements.
6. [Hand the conversation to a person](./PasarAUnAsesor). The agent intent and the help desk.
7. [Run a test suite](./CorrerUnaSuite). A CSV with what the bot should reply.
