# Credentials

**Credentials** is in Management. That is where you create the keys something
outside uses to talk to the workspace.

There are two tabs, and both read the same table:

- **API keys.** For CI, an SDK, or a script.
- **MCP.** So Claude Desktop, Claude Code, or Cursor can use the tree. When you create the key, the app copies the ready-made JSON. The walkthrough is in [MCP](/docs/Agente/Mcp).

Creating them requires an administrator. The full key is shown once, when you create it.
After that, only the identifier remains.

![Credentials, API keys tab. The other tab is MCP](/img/gestion/credenciales.png)

These are separate from the AI model keys for the builder agent: those
are stored per workspace in the agent settings, not on this screen.
