# Diagnostics

**Diagnostics** is in Management, and only an administrator can see it.

Three tabs:

- **Dashboard.** The recent status of runs.
- **Runs.** The list, with a filter by status.
- **Live logs.** The container output.

Use it to see why a tool, a script, or a turn failed, without signing in to
the server by hand.

![Diagnostics, Dashboard tab: how many runs there are and how many are still unreviewed](/img/gestion/diagnosticos.png)

**Runs** lists each one, with the message, the path, and the status. **Live logs** is the recent backend output.
