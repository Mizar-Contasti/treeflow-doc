# AI in TreeFlow

TreeFlow uses a language model to **help you build** the bot. It does not use it to **reply** to your users.

:::info The bot replies with what you build
When someone writes, the bot detects an intent and replies with the tree's flow and messages. There is no generative model inventing replies in the conversation. That is what makes it predictable: it says what you, or the agent, left written.
:::

## Where there is AI

| Function | What it is for | Where |
|---|---|---|
| [**Builder agent**](/docs/Agente/Constructor) | Create and modify flows, nodes, intents, entities, and messages by talking | Console → **Agent** tab |
| [**MCP server**](/docs/Agente/Mcp) | Let Claude Desktop, Claude Code, or Cursor do the same from outside | Management → [Credentials](/docs/Avanzado/Credenciales) → **MCP** |
| **Generative ingestion** | Extract intents and entities from a PDF or a CSV | Integration → Tools → **Generative Ingestion** and **Knowledge Base** |

The agent and ingestion use **your own key** from a model provider: TreeFlow does not ship its own model. See [Providers and models](/docs/Agente/ModelosGenerativos).

## How you reach them

The orange button at the bottom right opens the console. At the top there is a robot icon: that is the agent.
