# From the page

The **Developer** tab of [Web Chatbot Widget](./setup) is for whoever embeds the chat. If the site only pastes the snippet, you do not need to open it.

## Context variables

Each row is a name and a value. They travel on every message, and the bot reads them like any variable, with `{$nombre}`.

They act as defaults. If the page calls `injectContext`, those values replace the ones from the panel. A variable defined here is already present on the first turn, the welcome.

**Save Changes** stores them on the widget. Until you save, the test page does not see them.

## Debug mode

The **Debug mode** switch puts an inspect button next to each bot message. It opens the request and the response for that turn. It is for reviewing the published widget. The panel console has its own, in [Test the bot](/docs/Fundamentos/ProbarElBot).

## Control the chat

The notice in the panel says it: this is optional. Use it if the page has its own button, or if there is a signed-in user.

The element is `treeflow-widget`.

**Open or minimize**

```javascript
const widget = document.querySelector('treeflow-widget');
widget.open();
widget.close();
```

**Dark mode**, separate from the [Colors](./personalizacion#colores) switch:

```javascript
const widget = document.querySelector('treeflow-widget');
widget.setAttribute('dark-mode', 'true');
widget.removeAttribute('dark-mode');
```

**Data about who is on the page.** These replace the panel variables. The bot uses them as `{$nombre}`.

```javascript
const widget = document.querySelector('treeflow-widget');
widget.injectContext({
  usuarioId: 'usr_987',
  nombre: 'María González',
  plan: 'Empresarial'
});
```

**Send text** as if the person had typed it:

```javascript
const widget = document.querySelector('treeflow-widget');
widget.sendUserMessage('Hola, necesito ayuda con mi pedido');
```

**Clear the conversation** and start another session:

```javascript
const widget = document.querySelector('treeflow-widget');
widget.clearHistory();
```

The same code is on the tab, with a **Copy** button for each case.
