# Mensajes

**Mensajes** guarda los textos que el bot puede repetir. Un nodo del [flujo](./Flujos) o una [captura](./Capturas) apunta a uno de estos, en vez de escribir el mismo párrafo en cada sitio.

Guardar ya deja el texto listo: se lee de la base en cada turno.

## La lista

Arriba se busca por nombre. **Nuevo Mensaje** abre el editor vacío.

![Lista de mensajes: tarjetas, buscador y Nuevo Mensaje](/img/mensajes/lista.png)

- Un clic en el nombre abre el mensaje.
- La franja naranja pide confirmación para borrarlo.
- Si hay muchas tarjetas, abajo están las páginas.

## El editor

**Nombre del mensaje** es obligatorio. Los espacios pasan a `_` y al guardar queda en minúsculas, sin acentos. La `ñ` se conserva. **Descripción** es opcional: sirve para recordar para qué es, y el usuario no la ve.

![restaurante_saludo_response: el nombre, la descripción y el saludo en Default](/img/mensajes/editor.png)

**Guardar cambios** vuelve a la lista. Si el árbol tiene más de un idioma, junto al nombre están los idiomas: cada uno edita su propio texto.

## Respuestas por canal

El acordeón se llama **Respuestas por canal**. Hay dos clases de pestaña.

**Default** siempre está. Ahí el bloque es de tipo **Texto**: lo que el bot dice cuando el canal no trae una versión propia.

**Web** aparece cuando el canal web está conectado. Ahí el bloque es de tipo **Elementos enriquecidos**: párrafo, botones, imagen y el resto. WhatsApp, Telegram, Facebook, Instagram, Email, Slack, Discord, ElevenLabs y Avatares IA abren su pestaña igual que Web, sólo si ese canal está conectado, y el bloque también es de elementos enriquecidos.

En `restaurante_saludo_response` Default es el saludo en texto. Si el canal web está conectado, su pestaña puede llevar elementos enriquecidos: en `prompt_image_response` es una imagen. Quien escribe por la web recibe el bloque de Web. Otro canal, si su pestaña está vacía, recibe el texto de Default.

Dentro de una misma pestaña, cada **Bloque** es una variante. Si hay dos, el bot elige **uno al azar** en cada turno. Un bloque vacío no viaja y no entra en el sorteo. **Agregar Bloque** suma otra variante en la pestaña abierta.

En el texto, de las dos pestañas, caben [funciones](/docs/Avanzado/Funciones): `{$nombre}`.

## Default

En Default el tipo es **Texto**. El campo se llama **Texto de respuesta**. Encima hay tres botones:

![Default: el bloque de texto, con negrita, cursiva y subrayado](/img/mensajes/editor.png)

- **Negrita.** Lo seleccionado queda entre `**`, y se pinta en negrita.
- **Cursiva.** Queda entre `*`.
- **Subrayado.** Queda entre `__`.

El texto sale tal cual, con ese formato. **Contenido JSON**, en el mismo desplegable de tipo, guarda un objeto a mano cuando el canal espera ese formato.

## Web

En Web el tipo es **Elementos enriquecidos**. **Agregar Elemento** arma la lista, y se reordenan arrastrando.

![Web: el bloque de elementos enriquecidos, con una imagen](/img/mensajes/web.png)

| Elemento | Para qué |
|---|---|
| Párrafo | El texto. Puede haber varios en el mismo elemento |
| Imagen | Una URL y el texto alternativo |
| Video | URL, título y si arranca solo |
| Audio | URL y título |
| Archivo | URL, nombre y, si quieres, tamaño y extensión |
| Botones | Cada uno con etiqueta y una acción |
| Respuestas rápidas | Opciones cortas, como los botones |
| Acordeón | Un título que abre un contenido |
| Lista desplegable | Opciones y un botón para enviar la elegida |
| Ubicación | Título, dirección, latitud y longitud |
| Divisor | Una línea, con etiqueta opcional |
| Tarjeta | Título, subtítulo, imagen y botones |
| Carrusel | Varias tarjetas, una al lado de la otra |
| HTML / Web | Etiquetas o una variable |

Un botón puede **enviar texto** (eso es lo que escribe el usuario), mandar una **respuesta oculta**, **abrir una URL** o **disparar un evento**. También admite un icono y un color.

El HTML se limpia antes de pintarse. Pasan títulos, párrafos, enlaces, imágenes y listas. No pasan `script`, `iframe` ni `form`. Una variable se escribe `{$noticias}`.

## Dónde se usa

- En esta lista, con nombre, para reutilizarlo.
- En el nodo del [flujo](./Flujos), pestaña **Conversación**: el texto se escribe ahí o se elige uno de estos mensajes.
- En una [captura](./Capturas), como pregunta propia o como mensaje ya guardado.
