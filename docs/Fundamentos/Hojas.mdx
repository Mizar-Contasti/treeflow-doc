# Entidades

En el menú se llaman **Entidades**. Son los tipos de dato que el motor saca de una frase. Una hoja del lienzo es un nodo del flujo, no una entidad: ver el [editor visual](/docs/Fundamentos/EditorVisual).

Las entidades son el equivalente a las *entities* de otros sistemas de chatbots.

## ¿Qué es una Entidad?

Una entidad define un tipo específico de información que tu árbol puede reconocer y extraer de los mensajes del usuario. Las entidades son fundamentales para:

- Extraer información relevante de los mensajes
- Personalizar las respuestas según los datos proporcionados
- Permitir que el árbol tome decisiones basadas en valores específicos

## Estructura de una Entidad

Las entidades simples y compuestas en TreeFlow se basan en una estructura de **valores clave** y **sinónimos**. Esta estructura permite reconocer diferentes formas en que un usuario puede expresar el mismo concepto.

![Estructura de una Entidad](/img/docs/estructura_hoja.svg)

*Diagrama: Estructura de una entidad con valores clave y sus sinónimos asociados*

### Valores Clave

Los valores clave representan los datos específicos que la entidad puede identificar y extraer. Cada valor clave:

- Es un identificador único dentro de la entidad
- Representa un concepto o dato concreto
- Se utiliza internamente para procesar la información

### Sinónimos

Los sinónimos son las diferentes formas en que un usuario puede expresar el mismo valor clave. Cada valor clave puede tener múltiples sinónimos:

- Variaciones de escritura ("café", "cafe", "coffee")
- Expresiones coloquiales ("grande", "enorme", "extra large")
- Abreviaturas ("XL", "lg", "G")

### Funcionamiento

Cuando un usuario escribe un mensaje, TreeFlow:

1. Analiza el texto buscando coincidencias con los sinónimos definidos en las entidades
2. Cuando encuentra una coincidencia, extrae el valor clave asociado
3. Este valor clave se convierte en un parámetro estructurado que las ramas pueden utilizar

:::info Importante
Esta estructura de valores clave y sinónimos aplica principalmente a las entidades simples y compuestas. Las entidades regex funcionan con patrones de expresiones regulares en lugar de valores predefinidos.
:::

## Tipos de Entidades

TreeFlow soporta tres tipos principales de entidades:

### 1. Entidades Simples

Las entidades simples contienen una lista de valores y sus sinónimos. Son ideales para conjuntos finitos de opciones.

**Ejemplo:** Una entidad "sabor_helado" podría contener valores como:
- chocolate (sinónimos: choco, chocolatado)
- vainilla (sinónimos: vanilla, vainiya)
- fresa (sinónimos: frutilla, strawberry)

![Entidad Simple](/img/docs/hoja_simple.svg)

*Ejemplo: Estructura de una entidad simple con valores y sinónimos*

### 2. Entidades Compuestas

Las entidades compuestas describen **varias entidades simples que aparecen juntas** en la
frase. Sirven para leer de una vez algo que tiene partes: "2 empanadas de queso" son
una cantidad, un producto y un sabor, pero son *un solo* renglón del pedido.

Se definen por **filas**, igual que las frases de una intención. Cada fila es una
forma válida de decirlo:

```
@sys.number:cantidad @categoria_producto:categoria de @sabor_producto:sabor
@sys.number:cantidad @categoria_producto:categoria @sabor_producto:sabor
@sys.number:cantidad @categoria_producto:categoria
@categoria_producto:categoria @sabor_producto:sabor
```

Añade una fila por cada combinación que quieras cubrir: el mismo pedido en otro
orden, o con una parte de menos. El motor se queda con la fila que rellene más
huecos.

**Los dos puntos ponen nombre al parámetro.** `@Productos:producto` es la entidad
`Productos` guardada como `producto`, que es como la leerás en la respuesta. Sin los
dos puntos, el parámetro se llama igual que la entidad.

Una fila puede llevar **palabras literales** entre los huecos —el `de` del primer
ejemplo—. Si las escribes, tienen que estar en la frase del usuario.

![Entidad Compuesta](/img/docs/hoja_compuesta.svg)

*Ejemplo: Estructura de una entidad compuesta que combina múltiples entidades*

:::tip Una frase puede traer varias
"dame 1 empanada de pollo y 2 arepas de carne" son **dos** renglones, y la entidad
compuesta devuelve los dos. Ver [Parámetros con varios valores](/docs/Avanzado/Parametros#un-parámetro-con-varios-valores).
:::

### 3. Entidades Regex

Las entidades regex utilizan expresiones regulares para identificar patrones específicos en el texto.

**Ejemplo:** Una entidad para reconocer códigos de producto con el formato "ABC-12345".

## Entidades del Sistema

TreeFlow incluye entidades del sistema predefinidas para tipos de datos comunes. Estas entidades están optimizadas para reconocer formatos específicos de información sin necesidad de configuración adicional.

## Crear una Nueva Entidad

Para crear una nueva entidad:

1. Selecciona un árbol existente
2. Navega a **Entidades**
3. Crea una entidad nueva
4. Elige el tipo (simple, compuesta o regex)
5. Proporciona un nombre descriptivo para tu entidad
6. Configura los valores según el tipo de entidad
7. Guarda la entidad



## Mejores Prácticas para Entidades

1. **Nombres descriptivos**: Usa nombres que indiquen claramente qué tipo de información extrae la entidad
2. **Sinónimos completos**: Incluye todas las variaciones posibles de cada valor
3. **Organización adecuada**: Divide las entidades complejas en entidades más pequeñas y específicas
4. **Reutilización**: Crea entidades genéricas que puedan ser reutilizadas en múltiples ramas
5. **Prueba regularmente**: Verifica que tus entidades extraen correctamente la información en diferentes contextos

:::tip Consejo
Para mejorar la precisión de la extracción, proporciona ejemplos variados de cómo los usuarios podrían expresar los valores de la entidad.
:::
