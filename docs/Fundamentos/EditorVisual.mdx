# Flujos

Un **flujo** es un recorrido: nodos y flechas. El árbol puede tener varios. Uno está marcado **Principal**: es el que arranca la conversación.

En [modo principiante](./ModoPrincipiante) esta misma pantalla es el editor sencillo, el de tres campos. En avanzado es el lienzo completo. La dirección es la misma; cambia el modo del árbol.

## La lista

**Flujos** abre las tarjetas. Se puede buscar por nombre.

![La lista de flujos: el principal, duplicar y Nuevo Flujo](/img/flujos/lista.png)

- **Nuevo Flujo** crea otro recorrido, vacío.
- **Principal** es el de arranque. Siempre hay uno. No se borra.
- El icono de copiar duplica el flujo, con otro nombre.
- El icono de basura lo elimina, si no es el principal.
- **Plantillas** aplica una plantilla de industria sobre el árbol: intenciones, entidades y el dibujo. Reaplicar no pisa las preguntas de un parámetro que ya existía.

Al entrar a una tarjeta se abre el editor. Arriba hay dos pestañas: **Diseño**, el lienzo, y **Configuración**, el nombre del flujo y si es el principal.

## El lienzo

![El lienzo: el inicio, una intención, un evento y un salto a otro flujo](/img/flujos/lienzo.png)

Cada nodo se arrastra. Abajo a la izquierda están el zoom, centrar y **Tidy Up**, que acomoda los nodos.

El **+** naranja crea el nodo que toca según de dónde salgas:

- Desde un **contexto**, ofrece **Intención** o **Evento**.
- Desde una intención o un evento, ofrece **Contexto**.

La flecha café, debajo del +, se arrastra hasta otro nodo para unirlos. La línea continua es el camino de la conversación. La punteada es un evento.

| Nodo | Qué es |
|---|---|
| **Contexto** (verde) | Donde el bot espera. El de inicio se llama **Start**. Ahí están disponibles las intenciones de ese tramo. |
| **Intención** (naranja) | Un paso que se activa cuando el motor reconoce esa intención. El texto de la intención se edita en [Intenciones](./Ramas); el nodo la coloca en el recorrido. |
| **Evento** (rayo) | Lo que no es una frase reconocida: no entendió, no hubo respuesta, o cancelar. |

Una pastilla con el nombre de otro flujo, como `rama_principal`, es un salto: la conversación sale de este dibujo y entra en ese.

## El editor del nodo

Un clic en el nodo abre la columna de la derecha. Arriba, el **nombre** y el interruptor **Nodo activo**. Apagado, el nodo se queda en el lienzo pero no participa.

### Conversación

![Conversación del nodo: la intención, la respuesta y a dónde sigue](/img/flujos/conversacion.png)

- **Intención.** Cuál dispara este nodo. Si ya está usada en el flujo, el selector la marca **En uso**.
- **Respuesta.** El [mensaje](./Mensajes) que se manda cuando esa intención se capturó, después de pedir los datos que faltaban y después de las herramientas de este nodo.
- **Transición.** El nodo de destino, casi siempre un contexto, para abrir el siguiente tramo de intenciones. También puede pasar la conversación a una persona.

### Funcionalidad

![Funcionalidad: scripts, herramientas, la captura en curso y el webhook](/img/flujos/funcionalidad.png)

- **Scripts** y **herramientas.** Lo que el nodo llama afuera: un script, una API. Se eligen aquí; se crean en [Herramientas](/docs/Fertilizantes).
- **Termina una captura en curso.** Decide qué pasa si la persona dice esto *mientras* el bot le está pidiendo datos. Activado, la captura se da por terminada: es lo que quieres en cancelar o despedirse. Desactivado, que es lo de fábrica, la captura sólo se pausa: el bot contesta y retoma la pregunta, con lo que ya llevaba escrito. Preguntar el horario a medio pedido es una duda de paso; decir «cancela» no.
- **Llamar webhook en este nodo.** Al pasar por aquí se llama el webhook del agente, antes que a las herramientas. Si el agente no tiene uno activo, no pasa nada.

La pestaña se queda donde la dejaste al saltar de un nodo a otro: si estás repasando herramientas, no te devuelve a Conversación en cada clic.

## Guardar

**Guardar cambios**, arriba a la derecha, se enciende cuando hay algo sin guardar: un nodo movido, una flecha, una respuesta. Cerrar el editor no publica solo.

Si además cambiaste lo que el motor reconoce —la intención, sus patrones, una entidad—, el rayo del menú vuelve a naranja y hay que entrenar. Mover un nodo de sitio no cambia lo que el bot contesta; cambiar la intención sí.
