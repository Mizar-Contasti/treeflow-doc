# Modo principiante

Un árbol puede estar en modo **principiante** o **avanzado**. El principiante
esconde lo que no hace falta para armar un flujo y probarlo.

Con un árbol principiante, el menú no muestra:

- Intenciones
- Entidades
- Mensajes
- Capturas
- Herramientas
- Pruebas
- Historial
- Respaldos

Siguen visibles Flujos, Canales, Conversaciones, Mesa de ayuda, Cuentas y
Credenciales.

El lienzo de un árbol principiante es el flujo sencillo. El avanzado abre el
editor completo, con intenciones, entidades y el resto.

Diagnósticos sigue siendo sólo para administradores, en los dos modos.
