# Probar el bot

El botón naranja de abajo a la derecha abre la **consola**. Es un chat con el árbol, sin publicarlo. Tiene tres pestañas: **Consola**, el chat de prueba; **Agente**, el que modifica el árbol con una clave del workspace; y **Constructor**, para armar turnos de usuario y de bot. Esta página es la pestaña Consola y el modo debug.

El entrenamiento se lanza con el rayo del menú, **Entrenar**. Si el árbol no se ha entrenado nunca, la consola lo dice y el campo de texto queda apagado. Si ya se entrenó y después cambiaste intenciones o entidades, se puede seguir hablando: contesta con el último entrenamiento, hasta que vuelvas a entrenar.

## La barra

Encima del chat hay una barra.

- **Por defecto**, el primer botón, es el flujo de arranque. Elige otro flujo y la conversación se reinicia ahí.
- **Por defecto** o **Web**, el segundo, es el canal. El bot manda la variante de [mensaje](./Mensajes) de ese canal. Si esa pestaña está vacía, manda Default. Aparecen WhatsApp, Telegram y el resto sólo si el canal está conectado.
- La bandera, **Ejecutar intención al inicio**, elige una intención o un evento anclado al principio del flujo. Cada vez que empiezas o reinicias, se dispara sola.
- El insecto enciende el **modo debug**.
- El icono de copiar guarda el enlace de esta conversación. Se activa cuando ya hay un turno.
- La flecha hacia atrás deshace el último turno.
- La flecha circular reinicia la conversación.

Abajo se escribe, o se usa el micrófono. Un botón del mensaje del bot también cuenta como turno: si el botón envía texto, abre una URL o dispara un evento, la consola hace eso.

## Un turno

Escribes y pasa esto, en orden:

1. El motor mira el flujo en el que estás y la frase.
2. Elige una [intención](./Intenciones), o no reconoce nada.
3. Saca los [parámetros](/docs/Avanzado/Parametros) con las [entidades](./Entidades).
4. Si falta un dato requerido, pregunta con el texto del parámetro o con la [captura](./Capturas), y espera. Ese turno no llega todavía a la respuesta final.
5. Cuando los datos están, corre las herramientas del nodo, si las hay, y manda el mensaje de ese nodo para el canal elegido.

Tu frase sale en la burbuja naranja. La del bot es la respuesta. Si pulsaste un botón, la burbuja muestra la etiqueta, no el valor oculto.

## Modo debug

El insecto se pone amarillo. El turno deja de ser sólo dos burbujas y enseña cómo se decidió.

Antes de la respuesta del bot aparece una línea:

`intención · confianza · cómo coincidió`

La confianza es un porcentaje. El tercer dato es el método: entidad, patrón, modelo, o `no_match` si no reconoció la frase. Si es `no_match`, la línea se marca. Al abrirla están los **parámetros** y el valor de cada uno. Un valor vacío es un dato que todavía no vino: el siguiente turno debería preguntarlo.

Si el nodo llamó una herramienta, su tarjeta aparece ahí, en el orden en que corrió, antes del mensaje. Si la conversación pasó a una persona, no hay burbuja del bot: en debug se ve a quién le llegó.

Un clic en tu burbuja abre el **request**, lo que se envió. Un clic en la del bot abre el **response**, lo que contestó el motor. El cuadro tiene cuatro vistas. **Todo** es la que queda al abrir.

| Vista | Qué deja |
|---|---|
| Todo | el JSON completo |
| Parameters | `parameters` y `session_parameters` |
| Messages | el texto de la persona o la respuesta del bot |
| Metadata | el resto: intención, tiempos, sesión, herramientas, sentimiento |

La búsqueda y copiar usan la vista que esté abierta. Con el cuadro abierto, Ctrl+F va a esa búsqueda.

En la web y en la tablet, el borde izquierdo de la consola se arrastra y se ensancha. Al salir del debug vuelve a su ancho. En el teléfono el panel ya ocupa la pantalla.

Encender el debug abre el [flujo](./EditorVisual) que se está ejecutando. El lienzo marca el nodo de este turno y el camino que ya recorrió. Un turno nuevo sigue marcando el lienzo si ya estás en él.

El lápiz del turno abre esa intención para editarla.

## Qué revisar

- El nombre de la intención. Si no es la que esperabas, el patrón o el orden de [entendimiento](./Arboles) está decidiendo otra.
- `no_match`. La frase no entró en ninguna intención del flujo.
- Los parámetros. Si falta uno y el bot no pregunta, el parámetro no está en requerido o la captura no tiene pregunta.
- La respuesta. Si elegiste Web y sale el texto de Default, la pestaña Web de ese mensaje está vacía.
- Después de cambiar intenciones o entidades, entrenar otra vez. Un mensaje o una captura se leen en el momento: guardar ya alcanza.
