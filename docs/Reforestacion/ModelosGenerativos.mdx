# Proveedores y modelos

El agente no trae un modelo propio: habla con el de **tu proveedor**, con tu clave. Esta página dice cuáles hay, qué se configura de cada uno y cómo cambiar sin perder nada.

![El desplegable de proveedores en la configuración del agente](/img/agente/proveedores.png)

## Los proveedores

| Proveedor | Modelo que propone | URL base que propone |
|---|---|---|
| Anthropic (Claude) | `claude-3-7-sonnet-20250219` | `https://api.anthropic.com/v1` |
| Gemini (Google) | `gemini-2.0-flash` | la de Google (compatible con OpenAI) |
| Groq | `llama-3.3-70b-versatile` | `https://api.groq.com/openai/v1` |
| OpenRouter | `google/gemma-3-12b-it:free` | `https://openrouter.ai/api/v1` |
| Cerebras | `llama3.1-70b` | `https://api.cerebras.ai/v1` |
| xAI Grok | `grok-2-latest` | `https://api.x.ai/v1` |
| Mistral AI | `mistral-small-latest` | `https://api.mistral.ai/v1` |
| OpenAI | `gpt-4o-mini` | `https://api.openai.com/v1` |
| Ollama (Local) | `llama3` | `http://localhost:11434/v1` |
| Custom / Local LLM | `local-model` | `http://localhost:1234/v1` |

Son los valores que la pantalla rellena al elegir el proveedor. **Groq** y **OpenRouter** llevan la etiqueta *Gratis* en la lista, y **Cerebras** la de *Ultra-rápido*: son indicaciones de la app, no promesas de condiciones. Mira el plan de cada proveedor antes de depender de él.

## Qué se configura

| Campo | Qué es |
|---|---|
| **Proveedor** | Uno de los diez de arriba |
| **Nombre de la credencial** | Para reconocerla. Por defecto, el nombre del modelo |
| **API Key** | La clave. Necesaria en todos menos en Ollama y Custom |
| **URL base** | La del servidor. Se rellena sola; se cambia para un servidor propio o un *proxy* |
| **Modelo por defecto** | Uno de la lista, o el nombre de cualquier otro |

El modelo tiene que admitir **llamadas a herramientas** (*function calling*): el agente trabaja pidiéndole herramientas, y un modelo que no las admite no puede construir nada. Si el proveedor responde que el modelo no existe (404), revisa el nombre.

## Un servidor propio

**Ollama** y **Custom / Local LLM** sirven para un modelo que corre en tu máquina o en tu red. Necesitan la URL base y no piden clave. Cualquier servidor que entienda el formato de chat de OpenAI vale (`/chat/completions`).

:::note TreeFlow en Docker
La URL `http://localhost:11434` apunta a la máquina donde corre el **backend**. Si el backend está en un contenedor, `localhost` es el contenedor y no tu equipo: usa la dirección del equipo que lo aloja.
:::

## Varias credenciales

Puedes guardar **varias** credenciales en el workspace —por ejemplo una de Groq para pruebas y otra de OpenAI para trabajo serio— y cambiar entre ellas arriba del chat del agente. También se cambia de **modelo** sin salir.

- Una credencial se **edita** o se **añade** desde los mismos controles.
- Un encargo se puede **repetir con otro modelo** para comparar el resultado.
- La credencial es del **workspace**: todos los bots y todas las personas la comparten.

Cuando el chat no indica una, el agente usa **la primera** credencial de IA del workspace.

## La misma clave en otro sitio

La **ingestión generativa** de la Base de Conocimiento, que saca intenciones y entidades de un PDF o un CSV, usa también una credencial de IA del workspace. Ver [La IA en TreeFlow](/docs/Reforestacion/Introduccion).

No es lo mismo que las **Claves de API** de [Credenciales](/docs/Avanzado/Credenciales): esas sirven para que un programa externo hable con TreeFlow, no para el agente.
