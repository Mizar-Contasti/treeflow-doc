# La IA en TreeFlow

TreeFlow usa un modelo de lenguaje para **ayudarte a construir** el bot. No lo usa para **contestar** a tus usuarios.

:::info El bot contesta con lo que tú construyes
Cuando alguien escribe, el bot detecta una intención y responde con el flujo y los mensajes del árbol. No hay un modelo generativo inventando respuestas en la conversación. Eso es lo que lo hace predecible: dice lo que tú, o el agente, dejaste escrito.
:::

## Dónde sí hay IA

| Función | Para qué | Dónde |
|---|---|---|
| [**Agente constructor**](/docs/Reforestacion) | Crear y modificar flujos, nodos, intenciones, entidades y mensajes conversando | Consola → pestaña **Agente** |
| **Servidor MCP** | Que un asistente de fuera (por ejemplo Claude Desktop) cree y modifique el árbol | Gestión → [Credenciales](/docs/Avanzado/Credenciales) → **MCP** |
| **Ingestión generativa** | Sacar intenciones y entidades de un PDF o de un CSV | Integración → Herramientas → **Ingestión Generativa** y **Base de Conocimiento** |

El agente y la ingestión usan **tu propia clave** de un proveedor de modelos: TreeFlow no trae un modelo propio. Ver [Proveedores y modelos](/docs/Reforestacion/ModelosGenerativos).

## Cómo se llega a ellas

El botón naranja de abajo a la derecha abre la consola. Arriba hay un icono de robot: ese es el agente.
