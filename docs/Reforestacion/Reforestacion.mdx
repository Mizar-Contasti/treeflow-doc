# 🌱 Reforestación: IA Generativa para TreeFlow

La **Reforestación** es el sistema de inteligencia artificial generativa de TreeFlow que permite crear automáticamente Hojas (entidades) e Intenciones (intents) usando modelos de lenguaje avanzados.

## ¿Qué es Reforestación?

Reforestación es una herramienta revolucionaria que utiliza IA para expandir automáticamente las capacidades conversacionales de tu Árbol. En lugar de crear manualmente cada Hoja e Intención, simplemente describes la funcionalidad que necesitas y la IA genera todo el contenido estructurado.

### Características Principales

- **🤖 Generación Automática**: Crea Hojas e Intenciones con un simple prompt de texto
- **🎯 Adaptación Universal**: Se adapta a cualquier dominio o industria automáticamente
- **👁️ Vista Previa**: Revisa todos los cambios antes de aplicarlos a tu Árbol
- **📝 Historial Completo**: Registro detallado de todas las sesiones y modificaciones
- **🔄 Integración Perfecta**: Los elementos generados se integran seamlessly con tu Árbol existente

## Cómo Funciona

### 1. Análisis del Contexto Actual

La IA analiza tu Árbol existente para entender:
- Qué Hojas ya tienes definidas
- Qué Intenciones están configuradas
- El dominio y propósito de tu chatbot

### 2. Procesamiento del Prompt

Cuando describes una nueva funcionalidad, la IA:
- Identifica las **acciones** (verbos) necesarias
- Detecta los **objetos** (sustantivos) relevantes
- Determina las **intenciones** que se requieren

### 3. Generación Inteligente

El sistema genera automáticamente:

#### **Hojas (Entidades)**
```json
{
  "name": "agendar",
  "type": "simple",
  "values": [
    {
      "key": "agendar",
      "synonyms": ["agendar", "programar", "reservar", "solicitar", "pedir"]
    }
  ]
}
```

#### **Intenciones (Intents)**
```json
{
  "name": "agendar_cita",
  "patterns": ["quiero @agendar una @cita", "necesito @agendar mi @cita"],
  "entities": [
    {"name": "agendar", "required": false},
    {"name": "cita", "required": false}
  ],
  "responses": [
    {
      "type": "text",
      "value": "Perfecto, voy a {agendar} tu {cita} para la fecha disponible"
    }
  ]
}
```

## Estrategia de Entidades

### Separación Semántica

Reforestación utiliza una estrategia inteligente que separa automáticamente:

#### **Entidades de Acciones**
- Verbos y acciones que el usuario puede realizar
- Ejemplos: `crear`, `eliminar`, `modificar`, `consultar`, `enviar`
- Incluye sinónimos naturales para cada acción

#### **Entidades de Objetos**
- Sustantivos y conceptos sobre los que se actúa
- Ejemplos: `producto`, `usuario`, `pedido`, `mensaje`, `archivo`
- Incluye variaciones y sinónimos relevantes

### Ventajas de esta Estrategia

- **🎯 Mejor Desambiguación**: Distingue claramente entre "agendar cita" vs "cancelar cita"
- **🔄 Reutilización**: Las mismas acciones sirven para diferentes objetos
- **📈 Escalabilidad**: Fácil agregar nuevas acciones u objetos
- **🗣️ Naturalidad**: Patrones de conversación más naturales

## Variables Dinámicas

### Respuestas Personalizadas

Las respuestas generadas incluyen variables dinámicas que se reemplazan automáticamente:

```
Usuario: "quiero programar una consulta"
Bot captura: agendar = "programar", cita = "consulta"
Bot responde: "Perfecto, voy a programar tu consulta para la fecha disponible"
```

### Formato de Variables

- **Sintaxis**: `{nombre_variable}`
- **Coincidencia**: Las variables coinciden con los nombres de las entidades
- **Flexibilidad**: Se adaptan automáticamente al contexto capturado

## Flujo de Trabajo

### 1. Acceso a Reforestación

1. Navega a tu Árbol en TreeFlow
2. Selecciona **"Reforestación"** en el menú lateral
3. Verás la interfaz de generación con IA

### 2. Descripción de Funcionalidad

1. **Escribe un prompt descriptivo** de la funcionalidad que necesitas
2. **Ejemplos efectivos**:
   - "Sistema de gestión de citas médicas"
   - "Bot de soporte técnico para software"
   - "Asistente de reservas para restaurante"
   - "Gestión de inventario para almacén"

### 3. Vista Previa de Cambios

1. La IA analiza tu prompt y genera:
   - **Nuevas Hojas** con valores y sinónimos
   - **Nuevas Intenciones** con patrones y respuestas
   - **Análisis de confianza** (0-100%)

2. **Revisa cuidadosamente**:
   - Nombres de entidades
   - Sinónimos propuestos
   - Patrones de conversación
   - Respuestas generadas

### 4. Aplicación de Cambios

1. **Si estás satisfecho**: Haz clic en "Aplicar Cambios"
2. **Si necesitas ajustes**: Haz clic en "Cancelar" y refina tu prompt
3. **Los cambios se aplican automáticamente** a tu Árbol

### 5. Validación y Testing

1. **Ve a Ramas**: Verifica que las nuevas intenciones aparezcan
2. **Ve a Hojas**: Confirma que las nuevas entidades estén disponibles
3. **Prueba en el chat**: Valida que todo funcione correctamente

## Historial de Sesiones

### Registro Completo

Reforestación mantiene un historial detallado de:
- **Prompts utilizados**: Qué describiste en cada sesión
- **Cambios generados**: Qué Hojas e Intenciones se crearon
- **Fecha y hora**: Cuándo se realizó cada modificación
- **Estado de aplicación**: Si los cambios se aplicaron o cancelaron

### Beneficios del Historial

- **📊 Trazabilidad**: Saber exactamente qué cambió y cuándo
- **🔄 Reproducibilidad**: Repetir generaciones exitosas
- **📈 Aprendizaje**: Entender qué prompts funcionan mejor
- **🛡️ Seguridad**: Posibilidad de revertir cambios si es necesario

## Mejores Prácticas

### Prompts Efectivos

#### ✅ Prompts Recomendados
```
"Sistema de gestión de pedidos para restaurante"
"Bot de soporte técnico con tickets y resoluciones"
"Asistente de reservas hoteleras con check-in/check-out"
"Gestión de inventario con entrada y salida de productos"
```

#### ❌ Prompts Poco Efectivos
```
"Hacer un bot"
"Ayuda general"
"Conversación básica"
"Responder preguntas"
```

### Consejos para Mejores Resultados

1. **Sé específico sobre el dominio**: "gestión de citas médicas" vs "gestión general"
2. **Menciona las acciones principales**: "agendar, cancelar, modificar citas"
3. **Incluye el contexto de uso**: "para clínica dental" vs "para spa"
4. **Describe los objetos principales**: "citas, pacientes, tratamientos"

### Iteración y Refinamiento

1. **Comienza con prompts generales** para establecer la base
2. **Refina con prompts específicos** para casos particulares
3. **Revisa siempre la vista previa** antes de aplicar
4. **Prueba en el chat** después de cada aplicación

## Limitaciones y Consideraciones

### Limitaciones Actuales

- **Dependencia de claridad del prompt**: Prompts ambiguos generan resultados menos precisos
- **No modifica entidades existentes**: Solo crea nuevas, no edita las actuales
- **Requiere revisión humana**: Siempre revisa antes de aplicar cambios
- **Idioma principal**: Optimizado para español, funciona en otros idiomas con menor precisión

### Consideraciones de Uso

- **Backup recomendado**: Siempre ten una copia de seguridad de tu Árbol antes de cambios masivos
- **Testing exhaustivo**: Prueba todas las nuevas funcionalidades antes de producción
- **Iteración gradual**: Mejor hacer varios cambios pequeños que uno masivo
- **Validación de negocio**: Asegúrate de que los cambios alineen con tus objetivos
