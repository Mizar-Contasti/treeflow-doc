# Herramientas

En el menú están en **Integración → Herramientas**. Un [canal](/docs/Injertos/CanalesDeComunicacion) es por dónde habla la persona. Una herramienta es lo que el bot llama mientras recorre un nodo: un script, una API, el webhook o el paso a una persona.

![Herramientas de Cafetería: las pestañas y un script](/img/integracion/herramientas.png)

| Pestaña | Qué guarda |
|---|---|
| [Scripts](/docs/Fertilizantes/Scripts) | Código Python que corre dentro del bot. Ocho plantillas |
| [APIs](/docs/Fertilizantes/Apis) | Una llamada HTTP. Once plantillas |
| [Webhook](/docs/Fertilizantes/Webhook) | Una sola URL, la del árbol, que un nodo puede pedir |
| [Transferencias](/docs/Fertilizantes/Transferencias) | Cómo se pasa la conversación a una persona |
| [Base de conocimiento](/docs/Fertilizantes/BaseDeConocimiento) | Un CSV que crea un flujo, una fila por intención |
| [Ingestión generativa](/docs/Fertilizantes/IngestionGenerativa) | Un PDF, Excel o TXT del que un modelo saca intenciones |

En el nodo del flujo, pestaña **Funcionalidad**, se eligen. **Añadir script…** corre antes. **Añadir herramienta…** llama a las APIs después, cuando ya están los datos del turno. **Llamar webhook en este nodo** usa el webhook del árbol, antes que las APIs. Si no hay uno activo, no pasa nada.

La salida queda en la conversación con el nombre de la variable. Un mensaje la lee con `{$total_final}`.
