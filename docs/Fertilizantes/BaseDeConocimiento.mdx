# Base de conocimiento

La pestaña **Base de conocimiento** arma un flujo a partir de un archivo, sin modelo. La pantalla lo llama **Knowledge Base Determinista (CSV 1:1)** y lo marca **Sin IA (Gratis & Exacto)**.

![Base de conocimiento: el nombre del flujo, los dos checks y la zona para soltar el CSV](/img/herramientas/base-conocimiento.png)

## El archivo

CSV o TSV. Dos columnas.

| Columna 1 | Columna 2 |
|---|---|
| La frase, que pasa a ser la intención | El mensaje que contesta el bot |

**Omitir primera fila (encabezado de columnas)** está encendido de fábrica: la primera línea no se importa. **Eliminar acentos y tildes en frases/respuestas** normaliza el texto antes de crear las intenciones. Apagado, los acentos se quedan.

**Nombre del flujo (Branch) a crear en el bot** es el recorrido nuevo. El ejemplo del campo es «Preguntas Frecuentes Envíos». Cada fila queda como una intención de ese flujo, con su mensaje anclado. El subtítulo de la pantalla lo dice: la columna 1 es la frase y la columna 2 es el mensaje.

## Importar

Se arrastra el archivo a la zona punteada o se hace clic para buscarlo. El botón **Crear Flujo e Importar Hojas (CSV)** se enciende cuando hay archivo. Procesa las filas y dibuja el flujo.

**Entrenar Bot Ahora** lanza el entrenamiento para que esas frases entren en la consola. Sin entrenar, el flujo está creado y el motor sigue con el entrenamiento anterior.

Abajo, **Intenciones de conocimiento registradas** lista lo que ya se importó en este árbol. Si todavía no hay nada, el aviso pide seleccionar un archivo. Se puede volver a subir otro, con otro nombre de flujo: no pisa el anterior.
