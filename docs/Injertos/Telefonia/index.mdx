# Telefonía (Voz)

Conecta tu árbol conversacional con sistemas de telefonía para interactuar con tus clientes mediante voz.

:::info Roadmap 2027
La integración nativa con Voz (IVR/Twilio Voice) está planificada para el ciclo de desarrollo de 2027. Actualmente te sugerimos utilizar los **Fertilizantes** (Webhooks) para conectar tu árbol a plataformas de telefonía.
:::
