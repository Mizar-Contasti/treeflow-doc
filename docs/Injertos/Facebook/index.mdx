# Facebook Messenger

Conecta tu árbol conversacional con Facebook Messenger para interactuar con tus clientes en su red social favorita.

:::info Roadmap 2027
La integración nativa con Facebook Messenger está planificada para el ciclo de desarrollo de 2027. Actualmente te sugerimos utilizar los **Fertilizantes** (Webhooks) para enlazar tu árbol a Facebook mediante middlewares externos.
:::
