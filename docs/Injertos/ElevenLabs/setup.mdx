# Setup de ElevenLabs Voice AI

La integración de **ElevenLabs** habilita respuestas de voz ultrapresentes y realistas sintetizadas por modelos neuronales multilingües (`eleven_multilingual_v2`).

---

## 🎙️ Características
- **Voice Selection**: Selección de voces predefinidas o clonadas personalizadas de tu catálogo de ElevenLabs.
- **Text-to-Speech (TTS)**: Conversión en tiempo real del texto de respuesta NLU a clips de audio MP3 de alta fidelidad.

---

## 🛠️ Credenciales Requeridas

1. **ElevenLabs API Key**: Clave de API de tu cuenta [ElevenLabs](https://elevenlabs.io/).
2. **Voice ID**: Identificador de la voz a utilizar (ej. `21m00Tcm4TlvDq8ikWAM` - Rachel).

---

## 📋 Proceso de Configuración

1. Obtén tu API Key desde **Profile Settings** -> **API Keys** en ElevenLabs.
2. Ingresa a **Injertos** -> **ElevenLabs Voice AI** en TreeFlow.
3. Pega tu API Key y Voice ID.
4. Presiona **Guardar y Verificar Síntesis**.
