# Setup de Avatares IA (HeyGen & D-ID)

La integración de **Avatares IA** permite a tu chatbot responder con videos hiperrealistas generados dinámicamente mediante las APIs de **HeyGen** o **D-ID**.

---

## 👤 Características
- **Multi-Proveedor**: Compatibilidad nativa con HeyGen Streaming API y D-ID Animation API.
- **Avatar Customization**: ID de Avatar y Voice ID configurable para personalizar la apariencia y expresión del agente virtual.

---

## 🛠️ Credenciales Requeridas

1. **Provider**: HeyGen o D-ID.
2. **API Key**: Clave API del proveedor elegido.
3. **Avatar ID**: Identificador del avatar virtual.

---

## 📋 Proceso de Configuración

1. Obtén tu API Key y Avatar ID en la consola de HeyGen o D-ID.
2. Navega a **Injertos** -> **Avatares IA** en TreeFlow.
3. Elige el proveedor, pega las credenciales y presiona **Guardar y Conectar**.
