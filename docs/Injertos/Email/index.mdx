# Correo Electrónico (Email)

Conecta tu árbol conversacional con servicios de correo para automatizar flujos de atención y soporte vía email.

:::info Roadmap 2027
La integración nativa con Email (SendGrid/SMTP) está planificada para el ciclo de desarrollo de 2027. Actualmente te sugerimos utilizar los **Fertilizantes** (Webhooks) para disparar o leer tus correos electrónicos.
:::
