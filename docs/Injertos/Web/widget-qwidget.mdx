# 🎨 Widget Web (QWidget)

El Widget Web de TreeFlow, también conocido como **QWidget**, es un componente embebible que permite integrar tu chatbot en cualquier sitio web con solo 2 líneas de código.

{/* ![QWidget Demo](/img/qwidget-demo-placeholder.svg) */}

## Características Principales

### ✅ Integración Ultra Simple
Solo 2 líneas de código HTML para integrar el widget completo.

### ✅ Web Component Nativo
Construido como Web Component con Shadow DOM para aislamiento de estilos.

### ✅ CDN Global
Disponible vía jsdelivr sin necesidad de descargar archivos.

### ✅ Totalmente Responsive
Se adapta automáticamente a dispositivos móviles y desktop.

### ✅ Personalizable
Configura colores, título, posición y más mediante atributos HTML.

### ✅ Ligero
Solo 20KB optimizado para carga rápida.

## Instalación Rápida

### Paso 1: Agregar el Script

Agrega esta línea en el `<head>` o antes del cierre de `</body>`:

```html
<script src="https://cdn.jsdelivr.net/gh/Mizar-Contasti/treeflow-web-widget@main/dist/treeflow-widget.js"></script>
```

### Paso 2: Agregar el Widget

Agrega el componente donde quieras que aparezca:

```html
<treeflow-widget 
  endpoint="https://tu-backend.com/message"
  tree-id="tu-tree-id"
  title="Mi Asistente">
</treeflow-widget>
```

¡Listo! Tu chatbot está funcionando.

{/* ![QWidget Setup](/img/qwidget-setup-placeholder.svg) */}

## Configuración

### Atributos Disponibles

#### `endpoint` (Requerido)
URL del endpoint de tu backend TreeFlow.

```html
<treeflow-widget 
  endpoint="https://api.mibot.com/message">
</treeflow-widget>
```

#### `tree-id` (Requerido)
ID del árbol (bot) que quieres usar.

```html
<treeflow-widget 
  tree-id="6c295eca-5a9f-4588-b1db-1cf5c05f05ee">
</treeflow-widget>
```

#### `title` (Opcional)
Título que aparece en el header del chat.

```html
<treeflow-widget 
  title="Soporte Técnico">
</treeflow-widget>
```

**Por defecto**: "Asistente Virtual"

#### `primary-color` (Opcional)
Color principal del widget (botón y header).

```html
<treeflow-widget 
  primary-color="#E4572E">
</treeflow-widget>
```

**Por defecto**: "#E4572E" (naranja TreeFlow)

#### `position` (Opcional)
Posición del botón flotante.

```html
<treeflow-widget 
  position="bottom-right">
</treeflow-widget>
```

**Opciones**:
- `bottom-right` (por defecto)
- `bottom-left`
- `top-right`
- `top-left`

#### `welcome-message` (Opcional)
Mensaje de bienvenida inicial.

```html
<treeflow-widget 
  welcome-message="¡Hola! ¿En qué puedo ayudarte hoy?">
</treeflow-widget>
```

**Por defecto**: "¡Hola! ¿En qué puedo ayudarte?"

#### `placeholder` (Opcional)
Placeholder del input de texto.

```html
<treeflow-widget 
  placeholder="Escribe tu mensaje aquí...">
</treeflow-widget>
```

**Por defecto**: "Escribe un mensaje..."

### Ejemplo con Todas las Opciones

```html
<treeflow-widget 
  endpoint="https://api.mibot.com/message"
  tree-id="6c295eca-5a9f-4588-b1db-1cf5c05f05ee"
  title="Soporte 24/7"
  primary-color="#2563EB"
  position="bottom-left"
  welcome-message="¡Bienvenido! Estoy aquí para ayudarte."
  placeholder="¿Cómo puedo ayudarte?">
</treeflow-widget>
```

## Referencia de Bloques JSON

El widget renderiza diferentes tipos de contenido basado en la respuesta del backend. Aquí están los formatos soportados:

### Texto Simple
```json
{
  "type": "text",
  "text": "Hola, ¿cómo estás?"
}
```

### Tarjeta (Card)
```json
{
  "type": "card",
  "title": "Título de la Tarjeta",
  "subtitle": "Subtítulo opcional",
  "text": "Descripción detallada...",
  "image": "https://ejemplo.com/imagen.jpg",
  "actions": [
    { "label": "Ver más", "payload": "VER_MAS" }
  ]
}
```

### Carrusel
```json
{
  "type": "carousel",
  "items": [
    {
      "type": "card",
      "title": "Opción 1",
      "image": "https://...",
      "actions": [...]
    },
    {
      "type": "card",
      "title": "Opción 2",
      "image": "https://...",
      "actions": [...]
    }
  ]
}
```

### Imagen
```json
{
  "type": "image",
  "url": "https://ejemplo.com/foto.jpg",
  "title": "Texto alternativo"
}
```

### Video
Soporta YouTube, Vimeo y archivos directos (mp4).
```json
{
  "type": "video",
  "url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
}
```

### Audio
```json
{
  "type": "audio",
  "url": "https://ejemplo.com/audio.mp3",
  "title": "Podcast Episodio 1"
}
```

### Archivo
```json
{
  "type": "file",
  "url": "https://ejemplo.com/documento.pdf",
  "title": "Manual de Usuario.pdf",
  "size": "2.5 MB"
}
```

### Ubicación
Puede mostrar una ubicación o solicitarla.
```json
{
  "type": "location",
  "latitude": 40.416775,
  "longitude": -3.703790,
  "title": "Nuestra Oficina",
  "address": "Calle Principal 123"
}
```

### Respuestas Rápidas (Chips)
```json
{
  "type": "quick_replies",
  "items": [
    { "label": "Sí", "payload": "YES" },
    { "label": "No", "payload": "NO" },
    { "label": "Quizás", "payload": "MAYBE", "icon": "help" }
  ]
}
```

## API del Backend

El widget se comunica con tu backend mediante el endpoint `/message`.

### Request

```json
POST /message
Content-Type: application/json

{
  "type": "text",
  "value": "Hola, necesito ayuda",
  "tree_id": "6c295eca-5a9f-4588-b1db-1cf5c05f05ee",
  "session_id": "uuid-generado-automaticamente"
}
```

### Response

```json
{
  "response": "¡Hola! Con gusto te ayudo. ¿Qué necesitas?",
  "suggestions": ["Ver productos", "Hablar con soporte", "Rastrear pedido"],
  "session_id": "uuid-generado-automaticamente"
}
```

### Campos de Response

#### `response` (Requerido)
Texto de respuesta del bot.

#### `suggestions` (Opcional)
Array de sugerencias que se muestran como chips interactivos.

#### `session_id` (Opcional)
ID de sesión para mantener el contexto de la conversación.

## Características Avanzadas

### Componentes Ricos y Multimedia

El widget soporta una variedad de componentes interactivos para enriquecer la conversación:

#### 🎠 Carrusel Interactivo
- **Drag-to-Scroll**: Navega entre tarjetas arrastrando horizontalmente (táctil y mouse).
- **Snap-to-Card**: El carrusel se alinea automáticamente a la tarjeta más cercana al soltar.
- **Contenido**: Cada tarjeta puede incluir imagen, título, descripción y botones.

#### 🎵 Audio Mejorado
- **Visualización**: Muestra una onda de audio (waveform) visual.
- **Controles**: Reproducción/Pausa y duración del audio.
- **Diseño**: Integrado visualmente con el tema del chat.

#### 📁 Archivos Adjuntos
- **Descarga Directa**: Botón de descarga que fuerza el guardado del archivo.
- **Metadatos**: Muestra icono de tipo de archivo, nombre y tamaño.

#### 💬 Respuestas Rápidas (Chips)
- **Estilo Moderno**: Las opciones se muestran como "chips" o píldoras horizontales.
- **Iconos e Imágenes**: Soporte para iconos y pequeñas imágenes dentro de los chips.

### Sugerencias Interactivas

El widget muestra sugerencias como chips clicables:

```json
{
  "response": "¿En qué puedo ayudarte?",
  "suggestions": [
    "Ver productos",
    "Hablar con soporte",
    "Rastrear mi pedido"
  ]
}
```

{/* ![QWidget Suggestions](/img/qwidget-suggestions-placeholder.svg) */}

### Indicador de Escritura

Muestra automáticamente "Escribiendo..." mientras espera respuesta del backend.

### Sesiones Persistentes

El widget genera y mantiene un `session_id` único por usuario para mantener el contexto.

### Scroll Automático

Se desplaza automáticamente al último mensaje.

### Responsive Design

Se adapta automáticamente a:
- Desktop (ventana completa)
- Tablet (ventana mediana)
- Móvil (pantalla completa)

## Control Programático

### Abrir/Cerrar el Widget

```javascript
// Obtener referencia al widget
const widget = document.querySelector('treeflow-widget');

// Abrir el chat
widget.open();

// Cerrar el chat
widget.close();

// Toggle (abrir/cerrar)
widget.toggle();
```

### Enviar Mensaje Programáticamente

```javascript
const widget = document.querySelector('treeflow-widget');

// Enviar mensaje
widget.sendMessage('Hola desde JavaScript');
```

### Escuchar Eventos

```javascript
const widget = document.querySelector('treeflow-widget');

// Evento cuando se abre el chat
widget.addEventListener('open', () => {
  console.log('Chat abierto');
});

// Evento cuando se cierra el chat
widget.addEventListener('close', () => {
  console.log('Chat cerrado');
});

// Evento cuando se envía un mensaje
widget.addEventListener('message-sent', (event) => {
  console.log('Mensaje enviado:', event.detail.message);
});

// Evento cuando se recibe una respuesta
widget.addEventListener('message-received', (event) => {
  console.log('Respuesta recibida:', event.detail.response);
});
```

## Troubleshooting

### Problema: Widget no aparece

**Solución**: Verifica que el script esté cargado correctamente.

```javascript
// Verificar en consola
console.log(customElements.get('treeflow-widget'));
// Debe retornar la clase del componente
```

### Problema: Error de CORS

**Solución**: Configura CORS en tu backend.

```python
# FastAPI
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # En producción, especifica dominios
    allow_methods=["*"],
    allow_headers=["*"],
)
```

### Problema: Sesiones no persisten

**Solución**: Verifica que tu backend retorne el mismo `session_id`.

```json
{
  "response": "Respuesta del bot",
  "session_id": "mismo-id-recibido"
}
```

### Problema: Estilos no se aplican

**Solución**: Usa CSS Custom Properties dentro del Shadow DOM.

```css
/* ❌ No funciona */
.chat-message {
  color: red;
}

/* ✅ Funciona */
treeflow-widget {
  --text-color: red;
}
```

## Funcionalidades Avanzadas

### 🎤 Transcripción de Voz (STT)

El widget soporta transcripción de voz mediante Speech-to-Text cuando el backend tiene configurado el servicio de voz.

```html
<treeflow-widget 
  endpoint="https://api.mibot.com/message"
  tree-id="tu-tree-id"
  microphone="true">
</treeflow-widget>
```

**Características**:
- Grabación de audio con visualización de onda
- Transcripción automática mediante servicio STT
- Envío de metadata de transcripción al backend
- Soporte para pausar y cancelar grabación

**Metadata enviada al backend**:
```json
{
  "type": "text",
  "value": "texto transcrito",
  "stt_info": {
    "status": "enabled",
    "audio_duration": 3.5,
    "process_time": 0.8,
    "model_used": "whisper-large-v3",
    "realtime_factor": 4.375,
    "confidence": 0.95
  }
}
```

### 😊 Análisis de Sentimientos

El widget puede enviar información de sentimientos detectados en los mensajes del usuario.

**Sentimientos detectados**:
- `positive` - Mensajes positivos, agradecimientos
- `negative` - Quejas, frustración
- `neutral` - Mensajes informativos
- `question` - Preguntas

**Metadata enviada al backend**:
```json
{
  "type": "text",
  "value": "mensaje del usuario",
  "sentiment": {
    "type": "positive",
    "confidence": 0.85
  }
}
```

### 🪟 Estados del Widget

El widget tiene 3 estados visuales:

#### 1. **Closed** (Cerrado)
Círculo flotante en la esquina con ícono personalizable.

```html
<treeflow-widget 
  widget-icon="https://mi-cdn.com/icono.svg">
</treeflow-widget>
```

**Fallback automático**: Si el ícono falla al cargar, muestra emoji 🌙

#### 2. **Open** (Abierto)
Ventana de chat normal (350x500px por defecto).

#### 3. **Maximized** (Maximizado)
Pantalla completa para mejor experiencia en móviles.

```html
<treeflow-widget 
  enable-maximize="true">
</treeflow-widget>
```

### 🎛️ Controles del Widget

El widget incluye 3 botones de control:

- **Minimizar** (`−`): Reduce el widget al estado anterior
  - Desde `maximized` → `open`
  - Desde `open` → `closed`
- **Maximizar** (`⛶`): Alterna entre ventana y pantalla completa
  - Desde `open` → `maximized`
  - Desde `maximized` → `open`
- **Cerrar** (`×`): Cierra completamente el widget a `closed`

```html
<!-- Deshabilitar botón de maximizar -->
<treeflow-widget 
  enable-maximize="false">
</treeflow-widget>
```

### 🎨 Ícono Personalizado

Configura un ícono personalizado para el estado cerrado:

```html
<treeflow-widget 
  widget-icon="https://cdn.miempresa.com/logo.svg">
</treeflow-widget>
```

**Características**:
- Soporte para SVG, PNG, JPG
- Fallback automático a emoji si falla la carga
- Tamaño recomendado: 32x32px o 512x512px (SVG)

### ⏱️ Delay de Respuesta

Simula tiempo de "pensamiento" del bot:

```html
<treeflow-widget 
  response-delay="true"
  response-delay-seconds="2000">
</treeflow-widget>
```

**Uso**: Útil para dar sensación de procesamiento natural.

### 🐛 Modo Debug

Activa información de debugging en los mensajes:

```html
<treeflow-widget 
  debug="true">
</treeflow-widget>
```

**Muestra**:
- Request completo enviado al backend
- Response completo recibido
- Metadata de STT (si aplica)
- Información de sentimientos (si aplica)

## Mejores Prácticas

### ✅ Usa HTTPS

Siempre usa HTTPS para tu endpoint en producción.

```html
<!-- ❌ Evita -->
<treeflow-widget endpoint="http://api.mibot.com/message">

<!-- ✅ Mejor -->
<treeflow-widget endpoint="https://api.mibot.com/message">
```

### ✅ Maneja Errores

Implementa manejo de errores en tu backend.

```python
@app.post("/message")
async def handle_message(request: MessageRequest):
    try:
        response = process_message(request)
        return response
    except Exception as e:
        return {
            "response": "Lo siento, ocurrió un error. Por favor intenta de nuevo.",
            "error": str(e)
        }
```

### ✅ Optimiza Respuestas

Mantén las respuestas concisas y claras.

```json
{
  "response": "Tu pedido #12345 está en camino. Llegará mañana entre 9am-5pm.",
  "suggestions": ["Rastrear pedido", "Cambiar dirección", "Hablar con soporte"]
}
```

### ✅ Usa Sugerencias

Guía al usuario con sugerencias relevantes.

```json
{
  "response": "¿En qué más puedo ayudarte?",
  "suggestions": [
    "Ver productos",
    "Estado de mi pedido",
    "Política de devoluciones"
  ]
}
```
