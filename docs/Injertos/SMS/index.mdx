# SMS

Conecta tu árbol conversacional con servicios de SMS para alcanzar a usuarios sin conexión a internet.

:::info Roadmap 2027
La integración nativa con SMS (Twilio/AWS) está planificada para el ciclo de desarrollo de 2027. Actualmente te sugerimos utilizar los **Fertilizantes** (Webhooks) para disparar tus mensajes de texto.
:::
