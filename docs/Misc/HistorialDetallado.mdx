# Historial

**Gestión → Historial** es lo que ya pasó en el árbol. El registro de versiones del producto está en el [historial de cambios](/docs/changelog).

Tres pestañas.

| Pestaña | Qué deja |
|---|---|
| **Cambios** | Quién creó, modificó o borró un flujo, una intención o una entidad, y cuándo |
| **Entrenamientos** | Cada corrida: modo, estado, duración, y el detalle de intenciones y entidades |
| **Integraciones** | Las ejecuciones de scripts, APIs y el webhook: si salió bien, el tiempo y el error |

Arriba se filtra y se actualiza la lista. Un cambio se abre y muestra el antes y el después.

Los nodos y los mensajes no quedan en **Cambios**. Un entrenamiento que falló se ve en **Entrenamientos**, con el motivo. Si una herramienta no contestó, el detalle está en **Integraciones** y, para un administrador, también en [Diagnósticos](/docs/Avanzado/Diagnosticos).

Las copias del árbol no viven aquí. Están en [Respaldos](./ImportarExportar).
