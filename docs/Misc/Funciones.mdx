# Qué hay en la app

El menú de la izquierda es el mapa. Cada nombre es una pantalla distinta. El glosario está en [Terminología](/docs/Fundamentos/Terminologia).

![El panel y el menú: flujos, intenciones, entidades, mensajes y capturas](/img/intro/panel.png)

| Menú | Para qué |
|---|---|
| **Árbol** | El bot. Se planta, se configura y se entrena |
| **Flujos** | El dibujo del recorrido |
| **Intenciones** | Lo que el motor reconoce |
| **Entidades** | Los datos que saca de la frase |
| **Mensajes** | Los textos que puede repetir |
| **Capturas** | Cómo pide un dato que falta |
| **Canales** | Web, WhatsApp, Telegram y el resto |
| **Herramientas** | Scripts, APIs, webhook, transferencias |
| **Conversaciones** | Lo que ya se habló |
| **Mesa de ayuda** | Cuando la conversación pasa a una persona |
| **Diagnósticos** | Por qué falló una ejecución. Lo ve un administrador |
| **Cuentas** y **Credenciales** | Quién entra, y las llaves para hablar con el workspace desde fuera |

![Un flujo en el lienzo](/img/intro/flujo.png)

La consola, el botón naranja, prueba el árbol sin publicarlo. El agente de esa consola modifica el árbol si el workspace tiene una clave de modelo.

![La consola](/img/testeo/consola.png)
