# Qué hay en la app

El menú de la izquierda es el mapa. Cada nombre es una pantalla distinta. El glosario está en [Terminología](/docs/Fundamentos/Terminologia).

![El panel, con el árbol elegido](/img/intro/panel.png)

Arriba del menú está el **árbol** elegido. El engranaje abre su configuración. El **+** planta otro. **Panel** es la primera entrada, suelta, antes de los grupos.

## Conversación

| Entrada | Para qué |
|---|---|
| [Flujos](/docs/Fundamentos/Flujos) | El dibujo del recorrido |
| [Intenciones](/docs/Fundamentos/Intenciones) | Lo que el motor reconoce |
| [Entidades](/docs/Fundamentos/Entidades) | Los datos que saca de la frase |
| [Mensajes](/docs/Fundamentos/Mensajes) | Los textos que puede repetir |
| [Capturas](/docs/Fundamentos/Capturas) | Cómo pide un dato que falta |

En [modo principiante](/docs/Fundamentos/ModoPrincipiante) sólo se ve Flujos. El resto aparece en avanzado.

![Un flujo en el lienzo](/img/intro/flujo.png)

## Integración

| Entrada | Para qué |
|---|---|
| [Canales](/docs/Canales/CanalesDeComunicacion) | Web, WhatsApp, Telegram y el resto |
| [Herramientas](/docs/Herramientas) | Scripts, APIs, webhook, transferencias, las dos cargas de conocimiento |

## Operación

| Entrada | Para qué |
|---|---|
| Conversaciones | Lo que ya se habló. Se puede bajar a CSV |
| [Mesa de ayuda](/docs/Avanzado/MesaDeAyuda) | Cuando la conversación pasa a una persona |
| [Pruebas](/docs/Avanzado/Pruebas) | Suites de varios turnos |

## Gestión

| Entrada | Para qué |
|---|---|
| [Historial](./HistorialDetallado) | Cambios, entrenamientos y el registro de las herramientas |
| [Respaldos](./ImportarExportar) | Copias del árbol, a mano o solas |
| [Diagnósticos](/docs/Avanzado/Diagnosticos) | Por qué falló una ejecución. Lo ve un administrador |
| Cuentas | Quién entra al workspace |
| [Credenciales](/docs/Avanzado/Credenciales) | Claves de API y [MCP](/docs/Agente/Mcp) |

La consola, el botón naranja, prueba el árbol sin publicarlo. El [agente](/docs/Agente/Constructor) de esa consola modifica el árbol si el workspace tiene una clave de modelo.
