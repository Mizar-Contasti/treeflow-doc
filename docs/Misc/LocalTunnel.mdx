# Túnel

La URL pública de TreeFlow la abre **Cloudflare** (`cloudflared`), dentro del mismo Docker del [despliegue](./Despliegues). En producción son `https://app.tree-flow.com` y `https://api.tree-flow.com`.

LocalTunnel no se instala ni se configura con TreeFlow. Las guías que pedían `npm install -g localtunnel`, un servicio en el puerto 8001 o una ruta `/api/reforestacion` describen un arreglo que ya no está.

Para probar el widget en un teléfono, usa la URL del túnel del despliegue, o la [página de prueba](/docs/Canales/Web/setup#probarlo) del canal web.
