# Entidades de sistema

En el menú están en **Entidades**, pestaña **Sistema**. No se crean, no se editan y no se borran. En un patrón se citan con arroba: `@sys.number`, `@sys.date`, `@sys.time`.

La lista, con lo que reconoce cada una y en qué formato sale el valor, está en [Entidades](/docs/Fundamentos/Entidades).

![Las tarjetas de Sistema](/img/entidades/sistema.png)

Son 16. `sys.zipcode` es el código postal mexicano de cinco dígitos, y `sys.phone` está afinado para números de México. Si el dato no está en la lista, se crea una entidad simple, compuesta o regex.
