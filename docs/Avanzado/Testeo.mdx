# Pruebas y Aseguramiento de Calidad (Testeo)

TreeFlow cuenta con mecanismos robustos para probar tus árboles conversacionales y garantizar su fiabilidad tanto a nivel funcional para el diseñador, como a nivel de rendimiento masivo (End-to-End).

## Panel de Pruebas (Simulador Local)
Dentro del entorno de TreeFlow, cuentas con una ventana de chat simulada.
- Permite chatear con el árbol en tiempo real.
- Integra un **Monitor de Confidence Score**: Depurador que muestra con qué precisión (fuzzy vs machine learning) el motor está entendiendo tus frases y cómo extrae las entidades.

## Pruebas Automatizadas End-to-End (Playwright)

Para mayo de 2026, el proyecto introdujo una rigurosa suite de pruebas E2E montada sobre **Playwright**. Esto asegura que las características críticas de la aplicación jamás sufran regresiones.

### Bots Virtuales de Playwright
Cuando la suite de pruebas se ejecuta, levanta instancias invisibles de navegadores reales (Chromium, WebKit) y actúa como un humano a velocidades sobrehumanas:
- **Gestión de Árboles**: El bot entra, hace log in y navega hasta el Workspace correspondiente.
- **Creación de Entidades Complejas**: Prueba que las expresiones regulares de `@sys` guarden correctamente y parsea sinónimos masivos.
- **Inyección Masiva de Bloques Visuales**: Uno de los scripts más potentes (`rich_responses.spec.ts`) navega hacia el Editor de Mensajes y **crea más de 14 bloques visuales diferentes** secuencialmente tanto para la pestaña **Web** como para la pestaña de **Telegram** (renderizando acordeones, carruseles, audios, etc.) asegurando paridad total entre integraciones.
- **Guardado de Intenciones**: Prueba que las ramas complejas retengan sus contextos e intenciones al guardarse en la base de datos PostgreSQL.

Las pruebas E2E en TreeFlow son tu salvavidas; te garantizan que por más pesada que sea la refactorización de código que apliques, las funciones básicas que tus clientes usan siempre seguirán de pie.
