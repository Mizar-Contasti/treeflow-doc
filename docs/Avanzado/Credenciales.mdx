# Credenciales

**Credenciales** está en Gestión. Ahí se crean las llaves con las que algo de
fuera habla con el workspace.

Hay dos pestañas y las dos leen la misma tabla:

- **Claves de API.** Para CI, un SDK o un script.
- **MCP.** Para conectar el servidor MCP del workspace, por ejemplo con Claude Desktop.

Crearlas es de administrador. La clave completa se enseña una vez, al crearla.
Después sólo queda el identificador.

No confundir con las claves de los modelos de IA del agente constructor: esas
se guardan por workspace en la configuración del agente, no en esta pantalla.
