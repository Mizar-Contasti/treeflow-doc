# Consola

La **consola** es el panel de la derecha. Sirve para hablar con el árbol sin
publicarlo. Tiene tres pestañas.

| Pestaña | Para qué |
|---|---|
| Consola | El chat de prueba |
| Agente | Le describes el diseño y él opera el árbol: flujos, intenciones, entidades, mensajes, entrenamiento. La clave del modelo es la del workspace. También se puede hacer desde fuera, por [MCP](/docs/Avanzado/Credenciales) |
| Constructor | El constructor de diálogos: arma turnos de usuario y de bot para probar frases |

![La consola: el flujo, el canal y el campo para escribir](/img/testeo/consola.png)

El recorrido de un turno está en [Probar el bot](/docs/Fundamentos/Testeo).

## Modo debug

El icono del insecto, en la barra de la consola, activa el modo debug.

Con él encendido:

- un clic en el mensaje del usuario abre el **request**;
- un clic en el mensaje del bot abre el **response**;
- en web y tablet, el borde izquierdo de la consola se arrastra para ensancharla. Al salir del debug vuelve a su ancho.

En el teléfono el panel ya ocupa toda la pantalla y no se arrastra.

![Modo debug: la intención, la confianza y el nodo de este turno](/img/testeo/debug.png)

## Detalles de la sesión

El diálogo del request o del response tiene cuatro vistas. **Todo** es la que
queda seleccionada al abrir, y el tamaño del diálogo es el de esa vista.

| Botón | Qué deja |
|---|---|
| Todo | el JSON completo |
| Parameters | `parameters` y `session_parameters` |
| Messages | el texto del usuario o la respuesta del bot |
| Metadata | el resto: intención, tiempos, sesión, herramientas, sentimiento |

La búsqueda y el botón de copiar usan la vista que esté activa.
