# Widget web

El **widget web** es el chat que se pega en un sitio. No pide token: se enciende, se ajusta en el panel y se copia un snippet. Es un canal **Estable**.

![Web Chatbot Widget, con el estado Activa y la pestaña Funcionalidad](/img/canales/web.png)

## Activarlo

El árbol tiene que estar **entrenado**. Si no, el interruptor no pasa a Activa y la pantalla avisa «Bot no entrenado».

1. Elige el bot arriba a la izquierda.
2. Abre **Integración → Canales → Web Chatbot Widget**.
3. Enciende **Estado**. Pasa a **Activa** y aparecen las pestañas.
4. Ajusta lo que haga falta y pulsa **Guardar Cambios**, arriba a la derecha. El punto naranja del botón avisa de que hay cambios sin guardar.

| Pestaña | Para qué |
|---|---|
| [Funcionalidad](./Funcionalidad) | La intención al abrir, archivos, el retraso y el micrófono |
| [Textos, Colores, Tamaños y Responsive](./personalizacion) | Cómo se ve |
| [Desarrollador](./DesdeLaPagina) | Variables que viajan con cada mensaje, el modo debug y el control desde la página |

El icono de copiar, a la derecha de las pestañas, copia el snippet. El de al lado restablece las opciones a los valores de fábrica.

Arriba también están **Probar Ahora** y **Abrir página de prueba**.

## Pegarlo en el sitio

El snippet ya trae el script, la dirección de este TreeFlow y el id del árbol. No hay que rellenar el id a mano. Se pega antes de `</body>`:

```html
<script src="https://cdn.jsdelivr.net/gh/Mizar-Contasti/treeflow-web-widget@main/dist/treeflow-widget.js"></script>

<treeflow-widget
  endpoint="https://tu-servidor/message"
  tree-id="el-id-de-tu-arbol">
</treeflow-widget>
```

`endpoint` y `tree-id` salen ya escritos al copiar. Colores, textos y la intención de inicio no van en el HTML: el widget los pide al cargar, de lo que esté **guardado**.

Con el canal apagado, el widget deja de contestar.

## Probarlo {#probarlo}

**Probar Ahora** abre el chat dentro del panel, con lo que tienes en pantalla, aunque no esté guardado. Vuelve a pulsarlo y dice **Dejar de probar**.

**Abrir página de prueba** abre una página en blanco, sin login, con sólo este bot. Usa lo **guardado**. Si cambias un color y no guardas, la previsualización y esa página no coinciden. El mismo enlace refleja lo último que guardaste.

En producción el enlace sale de la API (`https://api.tree-flow.com/widget-demo/…`). En local apunta a tu máquina.

## Si no aparece

- El script tiene que cargar. Míralo en la consola del navegador.
- El `tree-id` es el del snippet, no uno escrito a mano.
- El interruptor tiene que estar en **Activa** y el árbol entrenado.
- Quien escribe por la web recibe la pestaña **Web** del mensaje. Si está vacía, recibe **General**. El detalle está en [Mensajes](/docs/Fundamentos/Mensajes).
