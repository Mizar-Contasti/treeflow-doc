# Desde la página

La pestaña **Desarrollador** de [Web Chatbot Widget](./setup) es para quien embebe el chat. Si el sitio sólo pega el snippet, no hace falta entrar aquí.

## Variables de contexto

Cada fila es un nombre y un valor. Viajan en cada mensaje y el bot las lee como cualquier variable, con `{$nombre}`.

Sirven de valor por defecto. Si la página llama a `injectContext`, esos valores pisan a los del panel. Una variable definida aquí ya está en el primer turno, el de la bienvenida.

**Guardar Cambios** las deja en el widget. Sin guardar, la página de prueba no las ve.

## Modo debug

El interruptor **Modo debug** pone un botón de inspección junto a cada mensaje del bot. Abre el request y el response de ese turno. Es para revisar el widget publicado. La consola del panel tiene el suyo, en [Probar el bot](/docs/Fundamentos/ProbarElBot).

## Controlar el chat

El aviso del panel lo dice: es opcional. Sirve si la página tiene un botón propio, o si hay un usuario con sesión.

El elemento es `treeflow-widget`.

**Abrir o minimizar**

```javascript
const widget = document.querySelector('treeflow-widget');
widget.open();
widget.close();
```

**Modo oscuro**, aparte del interruptor de [Colores](./personalizacion#colores):

```javascript
const widget = document.querySelector('treeflow-widget');
widget.setAttribute('dark-mode', 'true');
widget.removeAttribute('dark-mode');
```

**Datos de quien está en la página.** Pisan las variables del panel. El bot las usa como `{$nombre}`.

```javascript
const widget = document.querySelector('treeflow-widget');
widget.injectContext({
  usuarioId: 'usr_987',
  nombre: 'María González',
  plan: 'Empresarial'
});
```

**Mandar un texto** como si la persona lo hubiera escrito:

```javascript
const widget = document.querySelector('treeflow-widget');
widget.sendUserMessage('Hola, necesito ayuda con mi pedido');
```

**Vaciar la conversación** y empezar otra sesión:

```javascript
const widget = document.querySelector('treeflow-widget');
widget.clearHistory();
```

El mismo código está en la pestaña, con un botón **Copiar** por caso.
