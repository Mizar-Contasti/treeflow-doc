# Tutoriales

Guías cortas, en orden, con las pantallas del árbol **Cafetería** (rubro Restaurante). Cada una hace una sola cosa. Si quieres el detalle de cada botón, al final está el enlace a la página de referencia.

## El recorrido

1. [Crear un árbol](./CrearChatbotBasico). Entrar, plantar con el rubro y ver lo que ya trae.
2. [Probar en la consola](./ProbarEnLaConsola). Escribir, leer la respuesta y encender el modo debug.
3. [Pedir un dato que falta](./PedirUnDato). Un parámetro requerido y la pregunta que lo pide.
4. [Un mensaje con una función](./MensajeConFuncion). Meter en el texto lo que la persona ya dijo.
5. [Una respuesta para la web](./RespuestaEnLaWeb). El texto de Default y los elementos enriquecidos del canal web.
6. [Pasar la conversación a una persona](./PasarAUnAsesor). La intención de asesor y la mesa de ayuda.
7. [Correr una suite de pruebas](./CorrerUnaSuite). Un CSV con lo que el bot debe contestar.
