# Un mensaje con una función

Lo que el bot dice puede llevar un hueco. Se escribe entre llaves y el `$` marca la variable. Sin `$`, es texto fijo.

```
{$nombre}     el valor de la variable nombre
{nombre}      la palabra "nombre"
```

## El pedido de Cafetería

**Mensajes** abre la lista. Entra a `restaurante_hacer_pedido_response`. En la pestaña **Default**, el texto nombra lo anotado si ya hay pedido y, si no, pregunta qué preparar.

![restaurante_hacer_pedido_response: la función con $pedido](/img/funciones/mensaje.png)

```
{("¡Listo! Anoté " + $pedido + ". Te lo preparamos enseguida.") if $pedido else "¡Con gusto! ¿Qué te preparo?"}
```

| Llegó | Sale |
|---|---|
| `$pedido` = `2 empanadas de queso` | ¡Listo! Anoté 2 empanadas de queso. Te lo preparamos enseguida. |
| `$pedido` vacío | ¡Con gusto! ¿Qué te preparo? |

**Guardar cambios**. El texto se lee al contestar: no hace falta entrenar.

La misma sintaxis cabe en la pregunta de un parámetro o de una captura.

![Pregunta de numero: {$categoria_producto} y {$sabor_producto}](/img/funciones/pregunta.png)

```
¿Cuántas {$categoria_producto}s de {$sabor_producto} te preparo?
```

## Las que ya vienen

No hace falta crearlas. En cualquier mensaje el motor deja dos:

| Variable | Qué contiene |
|---|---|
| `{$last_utterance}` | Lo último que escribió la persona |
| `{$last_no_match}` | La última frase que el bot no entendió |

```
No entendí "{$last_no_match}", ¿puedes decirlo de otra forma?
```

Al teclear `{$` salen en el selector, marcadas como *Sistema*. Cuándo cambia cada una está en [Variables del sistema](/docs/Avanzado/Funciones#variables-del-sistema).

## Comprobarlo

Abre la consola, flujo **Restaurante**, canal **Por defecto**. Completa el pedido. La respuesta debe nombrar lo capturado.

![La consola ya sustituyó la categoría en la pregunta](/img/funciones/consola.png)

Si en la burbuja se ve una llave suelta, falta el `$` o la expresión no cerró con `}`. Una variable que no existe sale en blanco y no rompe el mensaje.

`{$nombre.original_value}` es cómo lo escribió la persona. `{$nombre.key_value}` es el valor normalizado.

La lista completa —condiciones, cuentas, `len`, listas— está en [Funciones](/docs/Avanzado/Funciones).
