# Crear un árbol

Este recorrido arma un bot de restaurante: saluda, toma un pedido y, si hace falta, pregunta el dato que faltó. El árbol de las capturas se llama **Cafetería** y se plantó con el rubro Restaurante.

## Entrar

Primero el espacio de trabajo, después el usuario.

![Inicio de sesión: el espacio de trabajo](/img/intro/login.png)

## Plantar

El **+** de arriba abre **Plantar un Nuevo Árbol**. Ahí se elige crear uno o importar un respaldo.

![Plantar: crear uno nuevo o importar](/img/empezando/plantar.png)

Al crearlo se pide el nombre, el rubro y el idioma. El rubro **Restaurante** deja intenciones, entidades, mensajes y el flujo ya dibujados. **Experimentado** lo deja en modo avanzado, que es el de estas capturas. **Primera vez** lo deja en [modo principiante](/docs/Fundamentos/ModoPrincipiante).

El panel queda con el árbol elegido. El rayo del menú entrena. En verde, el entrenamiento está al día.

![Panel de Cafetería, con el entrenamiento al día](/img/intro/panel.png)

## Lo que ya trae

**Intenciones** son los escenarios: saludo, menú, pedido, reserva.

![Lista de intenciones del restaurante](/img/intenciones/lista.png)

`hacer_pedido` guarda las frases y el parámetro `orden`.

![Editor de hacer_pedido](/img/intenciones/editor.png)

**Entidades** son los datos. `sabor_producto` es carne, pollo, queso y el resto.

![sabor_producto, con claves y sinónimos](/img/entidades/simple.png)

**Mensajes** son lo que el bot repite. El saludo dice para qué sirve.

![El saludo en la pestaña Default](/img/mensajes/editor.png)

## El recorrido

**Flujos** abre el dibujo. **Restaurante** tiene el contexto **Inicio**, una intención por escenario y el evento de cuando ninguna calza.

![El lienzo de Restaurante](/img/flujos/lienzo.png)

`saludo` manda el mensaje y vuelve a Inicio. `reservar_mesa` pregunta las personas si no vinieron en la frase. `hablar_con_asesor` pasa a una persona.

![saludo: intención, mensaje y vuelta a Inicio](/img/flujos/conversacion.png)

## Probarlo

La consola es el botón naranja. El primer botón elige el flujo. Para este mapa, **Restaurante**. `hola` contesta la bienvenida.

![hola en el flujo Restaurante](/img/diseno/recorrido.png)

Si cambias intenciones o entidades, vuelve a entrenar. Un mensaje o una captura se leen al guardar. El detalle está en [Probar el bot](/docs/Fundamentos/Testeo).
